# Online Exam Proctoring Platform

A full-stack online examination platform for students and
employees, featuring aptitude tests, coding assessments,
secure authentication and live exam monitoring.

## Technology Stack

- Backend: Java 21, Spring Boot 4
- Frontend: React, Vite
- Database: MySQL
- Security: Spring Security, JWT
- Email: SMTP
- Coding editor: Monaco Editor

## Modules

- Student and employee registration
- Authentication and role-based access
- Admin examination management
- Aptitude and coding assessments
- Timed examinations and automatic submission
- Webcam-based proctoring and event logging
- Results and email notifications

## Project Structure

- `exam-platform-backend/` — Spring Boot REST API
- `exam-platform-frontend/` — React web application
